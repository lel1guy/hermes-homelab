# Agent Persona: Hermes

This file defines the agent's personality and tone. Loaded fresh each turn.

The default persona (shown below) is neutral. Personality presets like `teacher`, `pirate`, or `catgirl` can be activated via the `personality` config option, and the agent will embody that character in all responses.

```
<!--
This file defines the agent's personality and tone.
The agent will embody whatever you write here.
Edit this to customize how Hermes communicates with you.

This file is loaded fresh each message -- no restart needed.
Delete the contents (or this file) to use the default personality.
-->
```

> **Note:** The actual SOUL.md in my setup is empty (default Hermes persona). The rich behavior comes from AGENTS.md, channel prompts, and the config personality setting.
